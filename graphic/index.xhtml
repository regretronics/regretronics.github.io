Technicore: graphical pages

Browse sources at bitbucket.org

  • 2-d raster:
    • test-01 (2018-11-25): My first experiment on per-pixel manipulation in HTML Canvas.
    • compress (2022-09-22): experiment with common image compression strategies.
    • noise-gen (2024-02-15): infinite texture (supports infinite panning and zoom in, but not infinite zoom out) (within the precision limits of floating-point numbers). Currently, requires keyboard for navigation.
    • canvas-float (2025-07-26): testing HDR, color spaces and floating-point pixel format.
    • resampling (2023-03-28): resampling experiment, not yet complete.
  • Three.js (mostly shader experiments):
    • test-06 (2024-09-26): volumetric 3-d with Beer's law of extinction (incomplete)
  • GPU.js:
    • 3d-voxels (2023-05-07): voxels with volumetric raycasting/ray marching. A maze of solid but translucent cubes. Using gpu.js for acceleration.
    • 3d-spheres (2023-07-02): volumetrically rendered balls that can mutually intersect. Bad performance.
  • Other 3-d:
    • 3d-voxels (2020-04-27): earlier JavaScript implementation of the above 3d-voxels, without acceleration.
