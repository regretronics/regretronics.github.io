Technicore: SVG experiments

Browse sources at bitbucket.org

All of those pages are free from JavaScript. A few use CSS. Most of them lack hardware acceleration in Firefox (as of 2026-01), yielding bad performance.

  • Based on Perlin noise:
    • texture-warp-noise (2025-05-13): noise texture deformed by transient noise, with cross-fade using SVG animation. Buggy in Chrome for Android as of 2025-12.
    • texture-dyn-warp-noise (2025-05-13): similar to above, but with varying colors as well. Heavy on GPU; may flick sometimes.
    • noise-blur.svg (2025-05-18): test about SVG Gaussian blur filter, through SVG animation.
    • noise-blur-02.svg (2025-05-22): similar to the previous one, but with stronger blur, and feGaussianBlur before feColorMatrix in the filter pipeline, which means the alpha channel is only removed after the blur. In Google Chrome (as of 2026-01) the implicit downsampling becomes obvious; the effect is so ugly you might have wished you haven't seen it.
    • noise-convolve.svg (2025-05-18): animated convolution effect. Currently has little effect in Chrome, and is slow in Firefox.
    • noise-map.svg (2025-05-19): variable blur, plus custom luminosity map.
    • noise-dyn-map-mono.svg (2025-05-19): variable texture, under custom color map.
    • noise-dyn-map.svg (2025-05-19): similar to above, but with hues map and more noise bandwidth.
  • shape-gradient.svg (2025-05-21): diffusion curves emulation.
  • motion-blur (2025-06-15): a trick using a combination of transforms and filters. Motion doesn't work in Firefox as of 2026-01, due to the CSS PRNG.
  • bevel-shading (2025-06-17): another experience with filters, this time involving feDiffuseLighting and feSpecularLighting for a 3-d effect. Not completely mature. Doesn't work in Firefox as of 2026-01, due to use of CSS formulas in SVG attributes.
    • bevel-map.svg (2025-06-19): companion to bevel-shading. Doesn't work in Firefox as of 2026-01.
  • See also: CSS pages (some use SVG).
