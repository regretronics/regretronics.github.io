Technicore: SVG experiments

Browse sources at bitbucket.org

  • Based on Perlin noise:
    • 2025-05-13-Noise: noise texture deformed by transient noise, with cross-fade using SVG animation.
    • 2025-05-13-Noise-dyn: similar to above, but with varying colors as well. Heavy on GPU; may flick sometimes.
    • 2025-05-18-Noise-blur.svg: test about SVG Gaussian blur filter, through SVG animation.
    • 2025-05-18-Noise-blur2.svg: similar to the previous one, but with stronger blur, and feGaussianBlur before feColorMatrix in the filter pipeline, which means the alpha channel is only removed after the blur. In Google Chrome (as of 2025-05) the implicit downsampling becomes obvious; the effect is so ugly you might have wished you've not seen it.
    • 2025-05-19-Noise-map.svg: variable blur, plus custom luminosity map.
    • 2025-05-19-Noise-dyn-map-mono.svg: custom color map, variable texture.
    • 2025-05-19-Noise-dyn-map.svg: similar to above, but with hues map and more noise bandwidth.
  • 2025-05-21-Shape-gradient.svg: diffusion curves emulation.
  • See also: CSS tests (some use SVG).
