Project ontological

Explanation:

Currently a content generator. Work in progress.

This project is inspired by a range of concepts, including formal grammars, dependency syntax, knowledge representation, symbolic artificial intelligence, narrow data, ontological categories.

The objective is to build an autonomous fiction generator or an "imaginator", generating a virtual world (more or less following the real one) with its due parts. But in this case, the approach is very abstract and analytical (unlike generating pixels, for example). This could have some creative and ludic applications, like increased replay value and flexibility from variable artificial situations in computer games.
