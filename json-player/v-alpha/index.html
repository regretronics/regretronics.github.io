This page uses two formats: a structured one (first), which allows hierarchies of parameters (frequency, volume, time scale, time displacement, decay factor, attack time), and a flattened one (non-recursive list), used when playing. But you don't have to worry with the flattened one until the last moment. This page encourages just intonation via prime factors and fractions.

The formats are based on an existing one, called JSON (JavaScript Object Notation, a computer language). The basic generic syntax for a structure node is: {"property1": value1, "property2": value2, ...} (known as an object). Like many computer languages, usage of alphabetic characters is case-sensitive and names are strict. Another syntax is [value1, value2, ...], when the values are implicitly indexed by natural numbers starting from zero (those objects are called arrays). That would be the same as {"0": value1, "1": value2, ...}. Anyway, you must use numerical indices (explicitly or not) to attach structures (i.e. patterns, subnodes; whether notes or blocks of notes) that should be played; you can use names (quoted strings) for node reuse, but for them to be played, they must be instantiated under a numerical index (e.g. "0": "myPattern", "myPattern": {...}). As it is a text format, it becomes easy to perfectly (and manually) save and load content. You can observe about proper usage of the format by using the generators; otherwise, we suggest using a code editor for increased productivity.

Block (inheritable) properties are:

freqRatio (multiplicative, default 1)
Can be used both for pitch tuning and interval accumulation.
volRatio (multiplicative, default 1)
Can be used to compensate for polyphony (like the generators do).
timeDelta (additive, default 0, relative to timeScale)
Time position or delay.
timeScale (multiplicative, default 1)
Inverse of tempo/speed.
decayFactor (substitutive, default 256)
Sustain time factor (how slowly the note amplitude is dampened while still playing).
attack (substitutive, default 0.125)
How slowly the note amplitude comes at its beginning.

Note properties are (influenced by block properties, and most of them relative factors):

noteStart (default 0)
The moment in time the note is played.
Influenced by timeDelta and timeScale.
noteStop (default noteStart + duration)
The moment in time the note is silenced.
Influenced by timeDelta and timeScale.
duration (default 1)
The amount of time the note plays. (You don't need both noteStop and duration—they are redundant.)
Influenced by timeScale.
freq (default 1)
Frequency, which represents pitch.
Influenced by freqRatio.
vol (default 1)
Amplitude, which represents volume.
Influenced by volRatio.
decayFactor (default 256)
Absolute override when present.
attack (default 0.125)
Absolute override when present.

Block and note properties support several number formats. Examples:

  • 1.25 = 1.25 (literal number)
  • "1.25" = 1.25 (text to number)
  • "5*0.5*0.5" = 5/4 = 1.25 (for expressions with operators, quote them as text)
  • "5/2/2" = (5/2)/2 = 5/4 = 1.25
  • "5/2^2" = 5/(2^2) = 5/4 = 1.25 (^ denotes exponentiation)
  • [-2, 0, 1] = 2-2 × 30 × 51 = 5/4 = 1.25 (uses prime factors implicitly)
  • {"2": -2, "5": 1} = 2-2 × 51 = 5/4 = 1.25 (great for use with prime factors)
  • Addition and subtraction are currently not supported, only sign change.
