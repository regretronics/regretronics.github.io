This page uses two formats: a structured one (first), which allows hierarchies of parameters (frequency, volume, time scale, time displacement, decay factor, attack time), and a flattened one (non-recursive), used when playing. But you don't have to worry with the flattened one until the last moment. This page encourages just intonation via prime factors and fractions.

The formats are based on an existing one, called JSON (JavaScript Object Notation, a computer language). The basic generic syntax for an object is: {"property1": value1, "property2": value2, ...}. Usage of alphabetic characters is case-sensitive and names are strict. Another one is [value1, value2, ...], when the values are indexed by natural numbers starting from zero (those objects are called arrays). That would be the same as {"0": value1, "1": value2, ...}.

Block (inheritable) properties are:

  • freqRatio (default 1)
  • volRatio (default 1)
  • timeDelta (default 0)
  • timeScale (default 1)
  • decayFactor (default 256)
  • attack (default 0.125)

Note properties are (influenced by block properties, and most of them relative factors):

noteStart (default 0)
The moment in time the note is played.
Influenced by timeDelta and timeScale.
noteStop (default noteStart + duration)
The moment in time the note is silenced.
Influenced by timeDelta and timeScale.
duration (default 1)
The amount of time the note plays. (You don't need both noteStop and duration—they are redundant.)
Influenced by timeScale.
freq (default 1)
Frequency.
Influenced by freqRatio.
vol (default 1)
Amplitude.
Influenced by volRatio.
decayFactor (default 256)
How slowly the note amplitude is dampened while still playing.
Absolute override when present.
attack (default 0.125)
How slowly the note amplitude comes.
Absolute override when present.

Frequencies, time scale and duration support several number formats. Examples:

  • 1.25 = 1.25
  • "1.25" = 1.25 (text to number)
  • "5*0.5*0.5" = 5/4 = 1.25 (for complex expressions, use text)
  • "5/2/2" = (5/2)/2 = 5/4 = 1.25
  • "5/2^2" = 5/(2^2) = 5/4 = 1.25 (^ denotes exponentiation)
  • [-2, 0, 1] = 2-2 × 30 × 51 = 5/4 = 1.25 (uses prime factors implicitly)
  • {"2": -2, "5": 1} = 2-2 × 51 = 5/4 = 1.25 (great for use with prime factors)
