This page uses two formats: a structured one (first), which allows hierarchies of parameters (frequency, volume, tempo and time), and a flattened one, used when playing. But you don't have to worry with the flattened one until the last moment.

Frequencies support several number formats:

  • 1.25 = 1.25
  • "1.25" = 1.25
  • "5/4" = 1.25
  • [-2, 0, 1] = 2^(-2) * 3^0 * 5^1 = 5/4 = 1.25 (uses prime factors implicitly)
  • {"2": -2, "5": 1} = 2^(-2) * 5^1 = 5/4 = 1.25 (for use with prime factors)
