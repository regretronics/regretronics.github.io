Technicore: CSS pages

Browse sources at bitbucket.org

Almost all of these pages are free from JavaScript.

  • Color:
    • palette-system (2024-08-23): experiment with system colors.
    • palette-system-simple (2026-01-01)
    • hdr-colors-test (2024-11-30): experiments with HDR and color spaces such as rec-2100. Not properly supported in browsers as of 2026-01:
      • In Chrome for Windows (as of 2026-01), some color spaces work, without an HDR effect.
      • In Chrome for Android (as of 2026-01), fewer color spaces work: display-p3-linear and rec2100-linear are not supported.
      • In Firefox (as of 2026-01), none of the color formats are supported.
    • spaces-and-hues (2025-03-10): some color operations and gamut testing. Uses some JavaScript. (Runs in Chrome, not in Firefox, as of 2026-01.)
    • color-scheme (2025-12-03): a few modern CSS experiments on color schemes, including the prefers-color-scheme media query. Uses the if() function, so as of 2026-01, it doesn't work in Firefox.
    • color-scheme-02 (2025-12-03): draft of a CSS color scheme engine. As of 2026-01, it doesn't work in Firefox.
    • supports-colors (2025-12-29): bulk testing of many CSS color values and expressions. Depends on an advanced usage of the attr() function, so as of 2026-01, it doesn't work in Firefox.
  • Animation:
    • wheels (2023-03-31): experiments with animations, interactivity, gradients, transform, animation-play-state, transitions.
    • 3d-translation (2023-11-23): experiment with perspective/perspective(), animation-composition, translate.
    • hover-trail (2023-11-23): experiment with transitions, :hover, transition-delay. Works better with a mouse.
    • shape-dyn-01 (2025-04-29): animated and parametric drawing; small experiment about using formulas in shapes, through CSS shape(). As of 2026-01, it works in Firefox 148.0beta, but the lack of accelerated rendering makes the performance bad.
    • shape-dyn-02 (2025-06-01): a more ambitious variation of the previous one, using Bézier curves, my PRNG, cubic spline interpolation. Doesn't work properly in Firefox as of 2026-06, due to the CSS PRNG, unaccelerated (software) rendering and blur filter limitations.
    • shape-dyn-03 (2026-11-20): circle disturbed by wave interference. Now using border-shape instead of clip-path, border-width, box-shadow, and no SVG at all. Doesn't work properly in Firefox as of 2026-11, due to border-shape, custom functions.
    • turbulence (2025-05-13): effect using SVG filters, blend modes, animated SVG, scroll-driven parameters. Doesn't work in Firefox as of 2026-01. Buggy in Chrome for Android as of 2026-01.
      • turbulence-anim.svg (2025-05-14): companion to turbulence.
    • anim-numerical (2025-05-20): experiment with crossbreeding of transitions and animations (through custom variables), math functions and interactivity, looking for complex or subtle possibilities. The animation-delay approach doesn't work in Firefox, as of 2025-05, but I've found an alternative.
    • anim-numerical-emulation (2025-05-22): more unconventional experiments, similar to the previous.
    • anim-spring-tests (2025-11-10): attempt to simulate elastic dynamics. Never matured.
    • scroll-spring (2025-11-25): experiments with scroll-driven animations. Includes a simulation of inertial elastic motion with overshoot. Scroll-driven animations don't work in Firefox as of 2026-01.
    • pause-gating (2025-11-28): incomplete. Relies on container queries, so it doesn't work in Firefox as of 2026-01.
    • cpu (2026-11-10): minimal example that works, to be expanded. Based on the "CPU" trick by Jane Ori. Only works in Chrome as of 2026-11.
  • 3-d:
    • segment (2023-03-25): lots of CSS math and transforms. Allows parallax scrolling.
    • particles (2023-04-08)
    • walls-01 (2025-05-29): initial test for a maze, with several controls. Doesn't work properly in Firefox as of 2026-10.
    • walls-02 (2026-10-24): a tube, hopefully lighter than its previous version. Mostly works in Firefox as of 2026-10.
    • heightmap (2026-10-19): a triangle mesh with random elevations, with many options. Mostly works in Firefox as of 2026-10.
  • Numerical:
    • vars-counters (2025-04-25): experiments with animations, counters, attr(), animation-timeline, @counter-style, content, sibling-index(). Doesn't work in Firefox as of 2026-01.
    • random-01 (2025-05-03): random-access (non-cumulative) PRNG (pseudo-random number generator). One of the few pages using JavaScript for something. Depends on an advanced usage of the attr() function, so as of 2026-01, it doesn't work in Firefox.
    • random-seq-interpolated (2025-05-04): PRNG with interpolation by cubic splines. Works with a reduced range in Firefox.
    • random-float32 (2025-07-30): Firefox-compatible PRNG. Not mature yet.
    • number-precision (2025-07-30): testing the precision of CSS floating-point numbers (as of 2026-01, Firefox uses float32 and Chrome uses float64).
    • random-squares (2025-08-12): another PRNG, adapted within the limits of float32. Based on the paper Squares: A Fast Counter-Based RNG by Bernard Widynski.
    • tracking-polar (2025-12-15): based on 2025-04-29-CSS-tracking; experiments with CSS math and CSS gradients.
    • test-sigmoid (2026-06-06): testing CSS numerical precision.
  • Metaball-like blobs:
    • blobs-original (found 2023-07-06) (not by me)
    • blobs-v02 (2023-07-06): some changes later.
    • blobs-v03-filter-warp (2023-07-07): texture deformation by particles, using SVG filters. This and later ones below don't work properly in Firefox as of 2026-01.
    • blobs-v03-filter-warp-02 (2024-08-22): more advanced control of deformation in each particle.
    • blobs-v04-random (2025-05-04): using my custom CSS PRNG. This and later ones below don't work at all in Firefox as of 2026-01.
    • blobs-v04-random-02 (2025-05-13): more SVG, less HTML.
    • blobs-v05-filter-map (2025-05-14): custom color map, using SVG filters.
    • blobs-v05-filter-map-mono (2025-05-15): similar to the previous, with a color map of oscillating luminosity.
    • blobs-v06-shaded (2026-03-02): using an animated SVG shading filter (feSpecularLighting and feDistantLight) and more precise gradients.
  • Miscellanea/simple tests:
    • css-misc-01 (2023-11-22): experiments with :has() and non-local effects, counters, attr(), oklch(), atan2(), polygon(), cubic-bezier().
    • css-misc-02 (2024-06-25): experiments with form controls, CSS custom variables, :has(), backdrop-filter, text-shadow, box-shadow, parametric page theme.
    • css-misc-03 (2024-07-11): experiments with :target, :focus-within, contenteditable, :has(), :hover, counters.
    • links-overlay (2025-04-25): URL hinting overlay UI experiment.
    • css-tracking (2025-04-29): experiment with element indexing, CSS anchors, counters, CSS math.
    • css-tracking-v02 (2025-05-01): same as above, improved with a few more tricks.
    • style-editor-live (2025-07-24): real-time CSS surgery.
    • filter-blur-sliced (2025-11-20): not mature yet.
    • css-funcs-01 (2025-12-04): misc. experiments with CSS custom functions, which are unsupported in Firefox as of 2025-12. Not mature yet.
    • test-url (2026-05-31): minor experiment on using URLs in CSS.
    • hashes (2026-10-20): experiment with links and URL targets. Not mature yet.
    • scroll-axes (2026-11-19): experiment with two scrolling axes that could become an arrow shooter game. Not mature yet.
