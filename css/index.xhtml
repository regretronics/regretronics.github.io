Technicore: CSS pages

Browse sources at bitbucket.org

Note: almost all of those pages are free from JavaScript.

  • Color
    • palette-system (2024-08-23): experiment with system colors.
    • hdr-colors-test (2024-11-30): experiments with HDR and rec-2100 (unsupported in browsers, as of 2025-05).
    • spaces-and-hues (2025-03-10): uses some JavaScript. (Runs in Chrome, not in Firefox, as of 2025-05.)
    • color-scheme (2025-12-03): a few modern CSS experiments on color schemes, including the prefers-color-scheme media query. Uses the if() function, so as of 2025-12, doesn't work in Firefox.
    • color-scheme-02 (2025-12-03): draft of a CSS color scheme engine. As of 2025-12, doesn't work properly in Firefox.
    • supports-colors (2025-12-29): bulk testing of many CSS color values and expressions. Depends on an advanced usage of the attr() function, so as of 2025-12, doesn't work in Firefox.
  • Animation
    • 2023-04-27-Anim: experiments with animations, interactivity, gradients, transform, animation-play-state, transitions.
    • 2023-11-23-CSS-anim: experiment with perspective/perspective(), animation-composition, translate.
    • 2023-11-23-CSS-trail: experiment with transitions, :hover, transition-delay.
    • 2025-04-29-Vector-dyn: animated and parametric drawing; small experiment about using formulas in shapes, through CSS shape(). Doesn't work in Firefox as of 2025-05.
    • 2025-04-29-Vector-dyn-v02: a more ambitious variation of the previous one, using Bézier curves, my PRNG, cubic spline interpolation. Doesn't work in Firefox as of 2025-05.
    • 2025-05-13-Turbulence: effect using SVG filters, blend modes, animated SVG. Doesn't work in Firefox as of 2025-05.
      • Noise-anim.svg: companion to 2025-05-13-Turbulence.
    • 2025-05-20-Anim-formulas: experiment with crossbreeding of transitions and animations (through custom variables), math functions and interactivity, looking for complex or subtle possibilities. The animation-delay approach doesn't work in Firefox, as of 2025-05, but I've found an alternative.
    • 2025-05-20-Anim-formulas-v02: more unconventional experiments, similar to the previous.
    • 2025-11-25-Scroll-anim: experiments with scroll-driven animations. Includes a simulation of inertial elastic motion with overshoot.
  • Numerical
    • vars-counters (2025-04-25): experiments with animations, counters, attr(), animation-timeline, @counter-style, content, sibling-index(). Doesn't fully work in Firefox as of 2025-05.
    • random-01 (2025-05-03): random-access (non-cumulative) PRNG (pseudo-random number generator). One of the few pages using JavaScript for something. Doesn't work in Firefox as of 2025-05.
    • random-02 (2025-05-04): PRNG with interpolation by cubic splines. Doesn't work in Firefox as of 2025-05.
    • number-precision (2025-07-30): testing the precision of CSS floating-point numbers (as of 2025, Firefox uses float32 and Chrome uses float64).
    • random-squares (2025-08-12): another PRNG, adapted within the limits of float32. Based on the paper Squares: A Fast Counter-Based RNG by Bernard Widynski.
    • tracking-polar (2025-12-15): based on 2025-04-29-CSS-tracking; experiments with CSS math and CSS gradients.
  • Metaball-like blobs:
    • Metaballs-original (found 2023-07-06) (not by me)
    • Metaballs-hc-v01 (2023-07-06): some changes later.
    • Filter-test-v03 (2023-07-07): texture deformation by particles, using SVG filters. This and later ones below don't work properly in Firefox as of 2025-05.
    • Filter-test-v04 (2024-08-22): more advanced control of deformation in each particle.
    • Filter-test-v05 (2025-05-04): using my custom CSS PRNG.
    • Filter-test-v06 (2025-05-13): more SVG, less HTML.
    • 2025-05-14-Color-map: custom color map, using SVG filters.
    • 2025-05-14-Color-map-mono
  • Tests/miscellanea
    • 2023-11-22-CSS-state: experiments with :has() and non-local effects, counters, attr(), oklch(), atan2(), polygon(), cubic-bezier().
    • 2024-06-25-CSS-state: experiments with form controls, CSS custom variables, :has(), backdrop-filter, text-shadow, box-shadow, parametric page theme.
    • 2024-07-11-CSS-state: experiments with :target, :focus-within, contenteditable, :has(), :hover, counters.
    • 2025-04-25-Links: URL hinting overlay UI experiment.
    • 2025-04-29-CSS-tracking: experiment with element indexing, CSS anchors, counters, CSS math.
    • 2025-04-29-CSS-tracking-v02: same as above, improved with a few more tricks.
    • 2025-07-24-Style-editor-live: real-time CSS surgery.
