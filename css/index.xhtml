Technicore: CSS pages

Browse sources at bitbucket.org

Almost all of these pages are free from JavaScript.

  • Color
    • palette-system (2024-08-23): experiment with system colors.
    • hdr-colors-test (2024-11-30): experiments with HDR and rec-2100 (unsupported in browsers, as of 2025-05).
    • spaces-and-hues (2025-03-10): some color operations and gamut testing. Uses some JavaScript. (Runs in Chrome, not in Firefox, as of 2025-05.)
    • color-scheme (2025-12-03): a few modern CSS experiments on color schemes, including the prefers-color-scheme media query. Uses the if() function, so as of 2025-12, doesn't work in Firefox.
    • color-scheme-02 (2025-12-03): draft of a CSS color scheme engine. As of 2025-12, doesn't work properly in Firefox.
    • supports-colors (2025-12-29): bulk testing of many CSS color values and expressions. Depends on an advanced usage of the attr() function, so as of 2025-12, doesn't work in Firefox.
  • Animation
    • wheels (2023-03-31): experiments with animations, interactivity, gradients, transform, animation-play-state, transitions.
    • 3d-translation (2023-11-23): experiment with perspective/perspective(), animation-composition, translate.
    • hover-trail (2023-11-23): experiment with transitions, :hover, transition-delay.
    • shape-dyn-01 (2025-04-29): animated and parametric drawing; small experiment about using formulas in shapes, through CSS shape(). Doesn't work in Firefox as of 2025-05.
    • shape-dyn-02 (2025-06-01): a more ambitious variation of the previous one, using Bézier curves, my PRNG, cubic spline interpolation. Doesn't work in Firefox as of 2025-05.
    • turbulence (2025-05-13): effect using SVG filters, blend modes, animated SVG. Doesn't work in Firefox as of 2025-05.
      • turbulence-anim.svg (2025-05-14): companion to turbulence.
    • anim-numerical (2025-05-20): experiment with crossbreeding of transitions and animations (through custom variables), math functions and interactivity, looking for complex or subtle possibilities. The animation-delay approach doesn't work in Firefox, as of 2025-05, but I've found an alternative.
    • anim-numerical-emulation (2025-05-22): more unconventional experiments, similar to the previous.
    • scroll-spring (2025-11-25): experiments with scroll-driven animations. Includes a simulation of inertial elastic motion with overshoot.
  • Numerical
    • vars-counters (2025-04-25): experiments with animations, counters, attr(), animation-timeline, @counter-style, content, sibling-index(). Doesn't fully work in Firefox as of 2025-05.
    • random-01 (2025-05-03): random-access (non-cumulative) PRNG (pseudo-random number generator). One of the few pages using JavaScript for something. Doesn't work in Firefox as of 2025-05.
    • random-seq-interpolated (2025-05-04): PRNG with interpolation by cubic splines. Doesn't work in Firefox as of 2025-05.
    • number-precision (2025-07-30): testing the precision of CSS floating-point numbers (as of 2025, Firefox uses float32 and Chrome uses float64).
    • random-squares (2025-08-12): another PRNG, adapted within the limits of float32. Based on the paper Squares: A Fast Counter-Based RNG by Bernard Widynski.
    • tracking-polar (2025-12-15): based on 2025-04-29-CSS-tracking; experiments with CSS math and CSS gradients.
  • Metaball-like blobs
    • blobs-original (found 2023-07-06) (not by me)
    • blobs-v02 (2023-07-06): some changes later.
    • blobs-v03-filter-warp (2023-07-07): texture deformation by particles, using SVG filters. This and later ones below don't work properly in Firefox as of 2025-05.
    • blobs-v03-filter-warp-02 (2024-08-22): more advanced control of deformation in each particle.
    • blobs-v04-random (2025-05-04): using my custom CSS PRNG.
    • blobs-v04-random-02 (2025-05-13): more SVG, less HTML.
    • blobs-v05-filter-map (2025-05-14): custom color map, using SVG filters.
    • blobs-v05-filter-map-mono (2025-05-15)
  • Miscellanea/simple tests
    • css-misc-01 (2023-11-22): experiments with :has() and non-local effects, counters, attr(), oklch(), atan2(), polygon(), cubic-bezier().
    • css-misc-02 (2024-06-25): experiments with form controls, CSS custom variables, :has(), backdrop-filter, text-shadow, box-shadow, parametric page theme.
    • css-misc-03 (2024-07-11): experiments with :target, :focus-within, contenteditable, :has(), :hover, counters.
    • links-overlay (2025-04-25): URL hinting overlay UI experiment.
    • css-tracking (2025-04-29): experiment with element indexing, CSS anchors, counters, CSS math.
    • css-tracking-v02 (2025-05-01): same as above, improved with a few more tricks.
    • style-editor-live (2025-07-24): real-time CSS surgery.
